# 审查报告：阶段3 演示效果修复（障碍生效/碰撞/路线可视化/窗口）（2026-08-20）

## 1. 变更范围

- **障碍真实生效**：建筑表改为世界坐标并刻意挡在 NPC 主路线——两栋挡 y=0
  巡逻/搜寻线（守卫 walk2/search 必经）、一栋挡支援兵响应线；`draw_map` 与
  `register_map_obstacles` 共用同一张表（单源，世界坐标 → 像素/网格自适应窗口）。
- **碰撞机制**：GodotBody 新增 `set_blocked_check`（移动步进与到达均检查阻塞单元，
  被挡即停止不穿行）；玩家移动前经 `is_pixel_blocked`（C++ → GDScript）拦截。
- **路线可视化**：每 NPC 32 个航点蓝点 + 1 个目标亮框（世界→像素刷新），
  寻路与绕行肉眼可见；E 放置木箱修正半单元视觉偏移并刷新路线标记。
- **窗口**：town 配置 1280×720；GridNav/玩家钳制/路线标记均按窗口自适应。
- 提示语更新（蓝点=路线 / 撞墙停 / E 放木箱）。
