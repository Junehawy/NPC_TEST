# 审查报告：阶段3 演示交互修复（名牌中文/树木障碍/NPC 互穿/放箱不卡死）（2026-08-20）

## 1. 变更范围

- **名牌**：多 NPC 名牌改用 `spec.label`（中文：守卫/支援兵/平民），白字、字号 13、
  位置 -90px 贴头顶（气泡上方，二者不重叠）。
- **树木障碍**：`kTreePos` 从 draw_map 局部提升为文件级共享表；树心注册为单单元
  障碍（树冠半径 0.26u ≈ 单元 0.25u），玩家与 NPC 均不可穿过（`is_pixel_blocked`
  与 blocked_check 统一走网格判定）。
- **动态占据碰撞（NPC/玩家互不穿透）**：新增 `kAgentRadius = 0.35u`；NPC 的
  blocked_check 与玩家的 is_pixel_blocked 均检查其他 NPC 与玩家当前位置（平方距离
  判定，self_node 排除自身）；GodotBody 被动态占据挡路时保持 `moving_` 原地等待
  （障碍移开或宿主重规划后下一帧继续），不再 `moving_ = false` 停死。
- **place_obstacle 防死角**：签名改为 `place_obstacle(dir_x, dir_y)`（GDScript 传
  玩家最近移动方向）；木箱放置到前方 2 单元处的 2×2 块（与玩家隔 1 单元空隙，
  不压脚下）；候选方向 前→顺时针→逆时针→反，全部被堵则打印提示放弃，避免把
  自己围进死角。player.gd 记录 `last_dir`。
- 纯适配层与资源（Godot 演示），框架零改动。
