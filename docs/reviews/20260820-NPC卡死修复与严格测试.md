# 审查报告：NPC 卡死修复与严格测试（2026-08-20）

## 起因
用户反馈："你他妈到底有没有认真测试就推送……随便一尝试就 NPC 卡住不动"。

## 复现与根因（严格排查，非猜测）

用卡死检测探针（连续 12s 位置+意图不变即判定卡住）复现出两类真实卡死：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 支援兵卡在 pace2 (0.9,-0.3)，意图 MoveIntent 不变 | 该目标落在挡守卫搜寻的建筑 (0.2,-0.6,0.8,1.2) **内部**（配置错误）；fallback 替代终点在两 cell 间**每帧跳变**，set_path 每帧重置到达标志 → move_done 永不触发 | pace2 目标移至建筑东侧空地 (1.6,-0.4)（探针验证从 +0.6u 目标改为可达目标后不再跳变） |
| 2 | 平民/守卫永久问候（SayIntent 你好呀），玩家站着不动就行为卡死 | greet 只有 player_near=false 才退出（玩家一直站着 → 永远问候）；且 idle→greet 无时长门槛，被同状态 walk1(elapsed 1s) 转换抢先导致有时不触发 | ①greet 增加 elapsed_ge 2.0 超时退出；②idle→greet 门槛 0.5s（低于 walk1 的 1s，保证玩家近距能及时问候） |

## 严格测试（新增 smoke_stress.gd，接入门禁）

- **4 场景 × 20s（共 80s）卡死检测**：①正常生活流（巡逻/逛街/往返）；
  ②单次枪声连锁；③连续放置 3 个木箱挡路；④玩家靠近平民触发问候 + 绕圈移动。
- 任何 NPC 连续 4 次采样（≈12s）位置与意图均不变 → 判定卡死，退出码 1。
- **门禁第 5 步扩为三连**：smoke_test（单 NPC）+ smoke_town（11 链路连锁）
  + smoke_stress（80s 压力）——以后每次推送前自动跑，杜绝"测试单一"。

## 验证结果

- [x] smoke_stress 80s 全场景 0 卡死
- [x] smoke_town 11 链路全 PASS；smoke_test/alt/bad 全 PASS
- [x] check-gate.sh 5/5 全绿（含新增压力冒烟）
- [x] 场景 4（持续开枪）中平民"反复躲藏"为合理行为（感知窗口 3s 内持续听到枪声），
  非卡死——已用真实操作场景 5（站出生点→靠近平民→单次开枪）验证无卡死
