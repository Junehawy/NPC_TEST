# 审查报告：城镇布局合理化（2026-08-20）

## 起因
用户反馈："你这房子都他妈跑哪去了，位置合理吗"。

## 问题确认
原布局多栋建筑压在道路中央：主路 y=0 上有两栋（-1.0,-0.6 与 0.2,-0.6），
市集棚/石屋/仓库也压着辅路——视觉上"房子建在马路中间"，不合理。

## 变更范围（R10-17）

### 布局重排（脚本校验：所有障碍 cell 与道路矩形零相交）
- **建筑 9 栋全部入街区**：北区 木屋(-5,1) / 市集棚(-2.4,1.1) / 花店(1.5,1.1) /
  旅店(-1.6,1.15) / 教堂(4.4,1)；南区 石屋(-5,-1.7) / 仓库(-1.4,-1.8) /
  民居(1.5,-1.9) / 谷仓(4.4,-1.9)。主路/辅路/街道全程畅通。
- **树木 15 棵**重排到草带/街区（避开道路 cell 与建筑，树间距 ≥0.8u）。
- **池塘**移入南草带西端 (-5.4,-1.4)；**花坛/路灯**同步避开道路。
- **NPC 目标点**全部移到道路/空地（脚本校验距建筑 ≥0.4u，避开建筑边缘）。

### 交汇死锁加固（压力测试暴露）
- 场景 4 玩家绕圈时守卫/平民"到达目标点后意图不变"——目标精确停在终点 cell
  内时 find_path 返回空（start==goal）、move_done 永不触发。
  修复：plan_paths 中路径空且起点与目标同 cell 时直接 report_action_result(completed)。
- 多 NPC 交汇互等：GodotBody 新增等待让步（被动态占据持续 1.2s 后 blocked_check
  不再挡其他 NPC/玩家，仅静态障碍仍硬挡），打破互相死锁。
