# 审查报告：阶段2 行为系统（2026-08-17）

## 1. 变更范围

- **接口层（RA-§3）**：`ICapability` 新增 `on_tick(Blackboard&, TickContext&)` 钩子
  （默认空实现，向后兼容）——决策器权威期间感知等模块仍可每 tick 处理；决策表 #35。
- **决策器（`npc_agent/decision/`，新增）**：FSM（条件迁移/意图模板/状态序列化）、
  Utility（计分+确定性噪声）、BT（selector/sequence/condition/action + done_when 相位推进、
  读档重置根 #19）——数据驱动、fail-fast 定义校验、同 IDecisionMaker 互斥单选。
- **感知模块（`npc_agent/capabilities/perception_module`，新增）**：stimulus.* 订阅 →
  环缓冲 → on_tick 打包 heard_&lt;type&gt; 旗标 + perception 视图。
- **动作回投**：`Agent::report_action_result` → action.completed/failed/cancelled 事件；
  `Agent::execute` 返回 ActionHandle；`Agent::tick` 出参 `ArbitrationRecord`。
- **决策日志 v1（`npc_agent/tracing/`，新增）**：DecisionTrace（R8 字段 JSON lines，
  dump/load/compare 严格一致）+ `AgentSystem::set_trace` + `tools/trace_replay` CLI。
- **验收场景（`npc_agent/testing/acceptance_scenario`，新增）**：FSM guard + 感知模块 +
  tick3 枪声确定性脚本，"听到枪声 → 警戒 → 呼叫支援 → 搜寻"。
- 文档：RA §8.2 目录树、§9 #35、§14 R8/R9、阶段 2 勾选与验收记录。
